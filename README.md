This is my first set of any kind of "programming" (I say with quotes because it is a very novice attempt at programming) which will be focused around helping to spark people's ideas to write poetry.
The first project is a simple poetry prompt generator which selects a random prompt with a button push from a list in the program. It also allows users to add their own prompts. Given the nature of randomness,
prompts may show up somewhat inconsistently. Future iterations will undergo feedback/testing from some folks and will incorporate as many ideas as my novice skills can.

The second project (random_metaphor) is a program that will let users enter in the building blocks of metaphors into three separate lists then click a button to throw them together in a random order. It's based off of a prompt that I used to use with paper and dice!
